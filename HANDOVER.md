## Publication blockers

The dataset must not be represented as a final public release yet:

1. Its license is still `LicenseRef-Pending`; source-specific redistribution
   rights have not been approved.
2. The packaged 4,177-row dataset was generated by the legacy linear SVM, not
   the current A2 XGBoost production manifest.
3. Two supplementary-material records have blank titles.
4. Ninety-six title/year groups (203 rows) need a documented versioning versus
   duplicate policy. Many are preprint/published-version pairs rather than
   simple duplicate IDs.
5. A completed 500-row operational audit found 59 non-AI and 8
   not-Sri-Lanka-relevant records; those decisions have not been propagated.
6. The dataset embeds an absolute local model path and must be regenerated with
   a portable model identifier.

The model is technically ready for handover, but its public license must also
be selected before a public model-hosting release.

## Keeping the app online

The project can stay online as long as an AWS EC2 instance (or equivalent
Docker host) remains provisioned and funded. The Compose services use
`restart: unless-stopped`, and pushes to `main` can redeploy through GitHub
Actions after the required repository secrets are configured. Availability is
therefore an infrastructure/account commitment, not something guaranteed by
the repository alone.

Before enabling public access, put the frontend behind HTTPS, set
`AUTH_COOKIE_SECURE=true`, use long random secrets, restrict SSH to an operator
IP, configure backups/monitoring, and decide who will pay for and operate the
host.
