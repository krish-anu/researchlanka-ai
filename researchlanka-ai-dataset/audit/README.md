# Release Audit Files

These CSV files are decision trails, not alternative publication datasets:

- `ai_review_adjudication_214.csv` records the outcome for every secondary
  `REVIEW` row from the 3,706-row release candidate.
- `duplicate_title_resolution_95_groups.csv` records the retained canonical
  work and removed versions for 95 connected title groups.
- `excluded_records_151.csv` records every row excluded during the final
  release-readiness audit and all applicable reasons.

The only public publication dataset is
`../data/researchlanka_ai_publications_v1.0.csv`.
